# 浪潮机器 · 推理芯片四十二年周期（1985–2026）

**线上地址：https://yjj0339.github.io/chip-cycle-42/** （手机可直接扫码打开，见 `qr-live.png`）

深度研究交互图谱：把推理芯片行业 42 年切成六个窗口——FPGA 创立、光通信繁荣与崩塌、安静的十年、TPU 点火、短缺与并购超级周期、当前 AI 周期——逐轮重建「需求点火 → 重复下单 → 产能到达 → 行业出清」的共同机制。

## 页面包含

- **26 张可交互图表**：四十二年墙图时间线、14 家公司生命线、HBM 与 CoWoS 产能、Top-4 资本开支压力表、机制矩阵、情景树等；
- **右侧数据面板**随章节滚动联动（关键数字 / 大事 / 机制进度）；
- **结论**：Base（2025→2028E ≈ 2.5×）/ Conservative（1.6×）/ Contraction（0.9×）三情景树；
- **Kill Switch 仪表**（大四家资本开支增速 +14% 警戒线）与 **八个可证伪触发器**（可交互拨动的「证伪台」，状态存于 localStorage）；
- 每张图右下角「源与数据」可钻取口径、来源清单与 **CSV 下载**；附录支持一键下载全部底层数据。

## 技术说明

- 零依赖纯静态单页（原生 SVG 图表引擎，无任何外部 JS/CSS/字体），GitHub Pages 直接可用；
- 浅色纸面编辑级排版；本页数据为公开资料整理与作者估算（以 E 标注），**不构成投资建议**。

## 本地运行

```bash
node tools/server.js 8342   # 打印局域网地址
node tools/shot.js          # 可选：自动滚动截图到 shots/（需本机 puppeteer-core 与 Chromium）
```
